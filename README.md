# 张鑫国际服 · ZHANG XIN GLOBAL SERVER

这是一个不接 AI 的静态英语学习网页，适合零基础、以出国实用英语为目标。

## 使用方式
1. 直接打开 `index.html` 可以体验（部分浏览器会限制本地跨域词库加载，但内置基础词库仍可用）。
2. 更推荐把整个文件夹上传到 GitHub Pages / Netlify / Vercel / Cloudflare Pages。
3. 部署在线后，网页会尝试载入 3000 个高频英语词条并缓存在浏览器环境中；若网络失败，会自动使用内置基础词库。
4. 学习进度、英文名、XP、错词、地图通关记录均保存在浏览器 localStorage，不需要账号。

## 已包含
- 第一次进入自己创建英文名
- 国际服护照
- 学习地图 / 区域解锁
- 单词训练
- 浏览器英文发音
- 听力训练
- 跟读模式
- 场景闯关
- 错词复习
- 救命英语
- 每日任务
- XP / 连续学习 / 成就
- 手机自适应

## 词库来源
在线高频词库使用 GitHub 开源项目：
arstgit/high-frequency-vocabulary（MIT License）
https://github.com/arstgit/high-frequency-vocabulary

网页不接入任何 AI API。
